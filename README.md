# Chapter & Charm Tambola

This is a mobile-first static website. To publish it, upload this folder to a static host such as Netlify, Vercel, or GitHub Pages. Once published, open the website, enter a name, and tap **Invite friends** to copy a room URL.

## Live-game note

The current version stores a player's ticket, marks, and drawn numbers in that player's browser. It is ready as a visual/gameplay prototype, but a true shared live game needs a real-time database (for example, Supabase or Firebase) so the host's drawn numbers automatically appear on every phone.
