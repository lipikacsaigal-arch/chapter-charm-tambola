# Chapter & Charm Tambola

This is a mobile-first multiplayer Tambola website. To publish it, upload this folder to a static host such as Netlify, Vercel, or GitHub Pages. Once published, open the website, enter a name, and tap **Invite friends** to copy a room URL.

## Live-game note

Run `supabase-setup.sql` once in your Supabase SQL Editor before publishing. Then the person who creates a room is the host; only their device can draw, while guests receive live number updates and play with individual tickets.
